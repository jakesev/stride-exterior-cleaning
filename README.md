# Stride Exterior Cleaning — published site

This repository holds the **built** website for Stride Exterior Cleaning,
published with GitHub Pages.

**Live preview:** https://jakesev.github.io/stride-exterior-cleaning/

## This is a preview address, not the production site

The business domain (`strideexteriorcleaning.com.au`) is not registered yet.
Until it is, this build is deliberately marked `noindex` and `robots.txt`
disallows crawling, so it can never compete with the real site in search
results for the same content.

## Source

The source — content JSON, templates, design system and the build script —
lives outside this repository, in the project folder under `v2/`. To change
anything, edit there and re-run:

```
node build.mjs --base=/stride-exterior-cleaning --origin=https://jakesev.github.io --preview --out=<this folder>
```

For the real domain, build without any flags and publish `v2/site`.

## Known gaps before this becomes the live business site

- **No phone number.** Not yet confirmed, so none is published.
- **Photography is licensed stock**, clearly labelled as demonstration.
- **No customer reviews** — the site shows an honest empty state rather than

## Algae and mould explainer (`algae-mould-explainer/`)

A narrated 3D presentation for customers: what the growth on roofs, walls and
paths is, how it damages each surface, and how soft washing removes it.

**Preview:** https://jakesev.github.io/stride-exterior-cleaning/algae-mould-explainer/

Unlike the rest of this repository, this folder is **written by hand, not
generated by `build.mjs`**. Keep it when re-running the build, or copy it into
the `v2/` source so the build carries it across.

- `index.html`, `explainer.css` — the page. It borrows the logo and Manrope
  font from `../assets/`; nothing else on the site depends on it.
- `explainer.js` — narration clock, camera moves, captions, labels. The script
  and its timings sit at the top of the file.
- `scene.js` — the house and the growth shaders. `closeups.js` — the
  cross-section drawings.
- `narration.mp3` — the voice-over, synthesised with the open-source Kokoro
  text-to-speech model (Apache 2.0). Re-recording it with a real voice only
  needs this file replaced and the timings in `explainer.js` updated.
- `vendor/` — three.js (MIT).

Add `?export` to the address to get the picture alone, with no page around it,
for screen recording or frame-by-frame capture.
